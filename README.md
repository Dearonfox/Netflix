## Netflix Clone (React)
TMDB 데이터를 이용해 영화 목록 조회/검색/찜 기능을 구현한 SPA입니다.

### Live Demo
- https://dearonfox.github.io/Netflix/#/

### Features
- 영화 목록(인기/최신/액션 등) 조회
- 검색
- 찜(Wishlist): localStorage 저장/해제
- 로그인/회원가입(localStorage 기반)
- 반응형 Header(모바일 햄버거 메뉴)

### Tech Stack
- React, TypeScript, React Router, Axios
- GitHub Pages (Actions)

### Run (Local)
```bash
npm install
npm start
